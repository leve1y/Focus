Приложение для Android-устройств, которое позволяет добавить на ваш рабочий стол виджет с расписанием уроков. Приложение полностью настраиваемое: можно выбрать дни, когда у вас каникулы, добавить своё расписание уроков, время их начала и конца и др.

### Что умеет эта программа:
* **Расписание на каждый день:** настраивается вручную.
* **Гибкое время уроков:** начало и конец настраиваются для каждого урока отдельно.
* **Настройка перемен:** можно выставлять время отдыха между занятиями.
* **Таймер на виджете:** показывает в реальном времени, сколько осталось до начала или конца урока/перемены.

### Что нужно:
* **Android 8.0+** (API 26)
* *Всё.*
