Застосунок для Android-пристроїв, який дозволяє додати на ваш робочий стіл віджет із розкладом уроків. Програма повністю налаштовується: можна вибрати дні, коли у вас канікули, додати власний розклад занять, час їх початку та завершення тощо.

### Що вміє ця програма:
* **Розклад на кожен день:** налаштовується вручну.
* **Гнучкий час уроків:** початок і кінець задаються для кожного уроку окремо.
* **Налаштування перерв:** можна виставляти тривалість відпочинку між заняттями.
* **Таймер на віджеті:** показує в реальному часі, скільки залишилося до початку чи кінця уроку/перерви.

### Що потрібно:
* **Android 8.0+** (API 26)
* *І все.*
